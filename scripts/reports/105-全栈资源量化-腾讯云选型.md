## 0. 会议要点速览（TL;DR）

| 维度 | 105 现状（Jetson Thor） | 换算到腾讯云的关注点 |
|---|---|---|
| GPU 形态 | **统一内存**（无独立显存），CPU/GPU 共享 122.8G | 腾讯云是**独立显存 dGPU**，需按下方显存合计选卡 |

| 架构 | **aarch64（Jetson 专用镜像）** | ⚠️ **腾讯云 x86 需重建镜像**（最大风险，见 §6） |

## 1. dinov3 是做什么的

### 1.1 它是什么

`dinov3-vitl16-pretrain-lvd1689m` = **Meta 的 DINOv3 自监督视觉基础模型（ViT-L/16）**，本项目用的是 LVD-1689M 预训练权重，模型体积 1.2G。

DINOv3 是 Meta 2025 年发布的自监督视觉骨干网络，特点是**无需标注**即可产出通用、高质量的**图像特征**，在分类、检索、分割、深度估计等下游任务上表现强（见 [DINOv3 技术解读](https://www.lightly.ai/blog/dinov3)、[DINOv3 说明](https://dinov3.org/help)）。

### 1.2 在本项目里的用途：**图片向量化（以图搜图 / 图文混合检索）**

现场确认的调用链（代码级证据）：

```
文档解析(parser/rag) 解析 PDF/Word 文档
   └─ 提取文档内插图 → 调 img_server: POST /v1/embeddings/image
        └─ img_service.py: AutoImageProcessor + AutoModel(dinov3) → 归一化向量
             └─ 写入 Milvus collection: images2
                  └─ 供知识库"以图搜图 / 图片检索 / 图文混合召回"使用
```

- 服务：`img_server` 容器（172.18.0.135:18080），启动命令 `python3 img_service.py`
- 代码：`/ManualAI/Omniknow/code/parser/rag/img_service.py`（99 行，FastAPI）
  - `MODEL_PATH = /ManualAI/models/dinov3-vitl16-pretrain-lvd1689m`
  - `device = cuda:0 if torch.cuda.is_available() else cpu` ← **走 GPU**
  - 输出：L2 归一化后的图像 embedding 向量
- 调用方：`parser/rag/parser/utils.py`（解析时抽图向量）、`parser/rag/tesla/tesla.py`
- 向量库：Milvus collection `images2`

**一句话**：dinov3 让知识库不只搜文字，还能**搜图片内容**——文档里的图会被向量化入库，问答时可按图检索。

### 2.4 显存口径说明（会上若被问）

- Jetson 是**统一内存**：上表数值是"从 122.8G 池子里分给 GPU 的部分"，不是独立显存。
- 换算到 dGPU（腾讯云）：**显存需求 ≈ 上表数值之和**，因为 vLLM/模型常驻显存。
- `--gpu-memory-utilization` 是**预留比例**（×122.83G），实测占用常低于预留：
  - 9B-AWQ：util 0.16 → 预留 19.7G，**实测 13.6G**
  - embedding：util 0.08 → 预留 9.8G，**实测 9.7G**
  - rerank：util 0.1 → 预留 12.3G，**实测 7.1G**
  - → **选卡按实测值 + 20% 余量**，不要按预留值累加（否则会高估）。

- 105 CPU：**14 核**（Thor SoC）
- **全项目 compose 无任何 CPU 限制声明**（无 `cpus:` / `cpu_quota` / `cpuset`）→ 所有容器**共享全部 14 核**，按需抢占。

## 6. ⚠️ 迁腾讯云的关键风险（务必在会上提）

### 6.1 架构不兼容（**最大风险**）

105 是 **aarch64 (Jetson Thor)**，而腾讯云 GPU 实例通常是 **x86_64 + NVIDIA dGPU**：

| 组件 | 105 用的 | 腾讯云需要 |
|---|---|---|
| vLLM 推理镜像 | `ghcr.io/nvidia-ai-iot/vllm:latest-jetson-thor`（51.2G，**Jetson/ARM 专用**） | 官方 x86 vLLM 镜像（如 `vllm/vllm-openai`）**需重建** |
| ASR/TTS | `qwen3-asr-jetson` / `qwen3-tts-jetson`（ARM，基于 Jetson 定制 torch 2.10） | x86 torch + 官方 qwen-asr/qwen-tts |
| mineru | `mineru-thor:latest`（53.1G，基于 Jetson vllm + **已卸载 vllm 走 transformers**） | x86 mineru 官方镜像 |
| img_server | `img-server-jetson`（40.2G，dinov3 + Jetson torch） | x86 torch + transformers（代码本身与平台无关 ✅） |
| 中间件 | mysql/redis/milvus/minio/nacos/es/rocketmq/kkfile | **官方 x86 镜像直接可用** ✅ |

**结论**：**中间件与纯 CPU 业务（含 MetaManual）可平滑迁移；AI 推理服务需按 x86 重建镜像并重新验证**。

### 6.2 其它注意点

1. **Jetson 专属参数需调整**：`--enforce-eager`（Jetson 上 CUDAGraph 无收益）在 dGPU 上**建议改回 CUDAGraph 以获得加速**。
2. **统一内存假设失效**：Jetson 上 `--gpu-memory-utilization` 是"占 122.8G 的比例"，dGPU 上变成"占显存的比例"，**需按显存重新标定**（例：A100 80G 上 0.16 → 12.8G）。
3. **cleanup-mem.sh 不再需要**（UVM 残留问题为 Jetson 特有）。
4. **ASR/TTS 协议不变**：OpenAI 兼容 `/v1/audio/transcriptions` 与 vllm-omni WS `/v1/audio/speech/stream` 是业务约定，迁平台后必须保持。
5. **HTTPS 安全上下文**：浏览器麦克风要求 HTTPS，nginx 8376 的证书配置要跟着迁。
6. **模型可复用**：模型权重（9B-AWQ/ASR/TTS/embed/rerank/dinov3）**格式通用，可直接搬**，无需重训。

## 8. 现场验证命令（会上可现场演示）

```bash
# GPU 逐进程显存（本项目最有用的一条）
nvidia-smi --query-compute-apps=pid,process_name,used_memory --format=csv

# 容器 → GPU 归属
for pid in $(nvidia-smi --query-compute-apps=pid --format=csv,noheader); do
  cid=$(grep -oE 'docker[-/][0-9a-f]{12,}' /proc/$pid/cgroup 2>/dev/null | head -1 | sed 's#docker[-/]##')
  echo "PID $pid -> $(docker inspect --format '{{.Name}}' $cid 2>/dev/null | sed 's#^/##')"
done

# CPU / 内存 / 磁盘水位
docker stats --no-stream --format '{{.Name}}|{{.CPUPerc}}|{{.MemUsage}}' | sort -t'|' -k2 -hr | head -15
free -h; df -h /
nproc
```

## 9. 一句话总结（可直接用于会议发言）

> 105 上整套系统跑在 **14 核 CPU + 122G 统一内存** 上；**GPU 实测共占用约 60.6 GiB**，其中**主交付栈约 44.7 GiB**（对话 LLM 13.6G、文本向量 9.7G、语音识别 9.8G、重排 7.1G、语音合成 2.2G、图片向量 1.2G、文档解析峰值 7G）。
> 迁腾讯云时：**中间件与纯 CPU 业务（含升版 MetaManual，约占 22G 内存、不吃 GPU）可平滑迁移**；**AI 推理服务是 Jetson/ARM 专用镜像，必须按 x86 重建并重新标定显存参数** —— 这是本次推广落地的主要工作量与风险点。
> 建议首发机型：**单卡 ≥48G 显存 + 16 vCPU + 64G 内存 + 1T 磁盘**（只推主栈），升版 MetaManual 另配 32G 内存。
