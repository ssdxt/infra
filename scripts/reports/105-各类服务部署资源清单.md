## 9. 已知资源风险（现场确认）

1. **内存余量仅 20G + swap 已用 24G** → 高峰或 27B 重启极易出现 vLLM 启动失败（`Free memory ... less than desired GPU memory utilization`）。**停 GPU 容器后必须 `bash /usr/local/bin/cleanup-mem.sh`**。
2. **磁盘 94% 已用，仅剩 223G** → 再 load 大镜像（如 asr_api 267G）会直接爆盘。历史 tar 备份在 `/ManualAI/images`(122G)，可按需清理。
3. **MetaManual 栈白占约 21G 内存**（czy-server/t-apass/czy-user），若与主业务无关建议停掉。
4. **端口冲突历史**：`holarfileparse_sgl_1.2b`(17199) 曾与 mineru-api 冲突；新服务上线前先核对端口唯一性。
5. `ai_nginx` 使用 host 网络（`docker inspect` 显示 IP 为 invalid，属正常）。
