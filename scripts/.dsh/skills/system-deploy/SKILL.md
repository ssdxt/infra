# 系统安装与部署（AI 私有化交付）

## 阶段一：环境检查（先于任何安装）
- OS / 内核 / 架构：`uname -a`、`cat /etc/os-release`
- 资源是否达标：CPU、内存、磁盘（含预留空间）、IO
- 网络：出网连通性、必要端口、内网仓库可达性
- 时间同步（避免证书/认证类故障）
- 显卡环境（如涉及 GPU）：`nvidia-smi`、驱动与 CUDA 版本匹配

## 阶段二：依赖与运行时
- 按交付清单核对：运行时（Python/Node/…）、容器引擎、驱动、系统库；
- 版本锁定：记录/校验确切版本，避免"装最新"导致的兼容漂移；
- 冲突处理：新旧版本、多版本共存时明确约定路径与默认值。

## 阶段三：安装执行
- 用受控方式（安装脚本/容器/清单），避免手工散装；
- 每个大步骤后做一次状态快照（成功/失败/回滚点）；
- 日志留存到统一位置，方便复盘。

## 阶段四：验证
- 服务存活、端口监听、健康接口返回；
- 核心功能冒烟测试；
- 与交付清单逐项核对。

## 阶段五：回滚与收尾
- 明确回滚方式与触发条件；失败不掩盖，报告清楚；
- 记录部署信息：时间、版本、配置差异、遗留问题；
- 更新交付/操作文档。

## 边界
- 安装到生产/客户环境前先备份可回滚点；破坏性操作先确认。
- 不确定某步对系统的影响时，先查再动。
