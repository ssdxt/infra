## 四、前端 `index.html` 三方案

| 方案 | 做法 | 优点 | 缺点 | 建议 |
|---|---|---|---|---|
| **A 同源相对路径** | `base_api=''`（或 `/api` 前缀），`voice_api='/voice'`；nginx 按前缀路由 | **一次改造永久免 IP**；零渲染 | 需要入口反代（形态 A/B 都有） | ✅ **推荐** |
| B 运行时渲染 | 镜像启动 `envsubst < index.tpl.html > index.html` | 保留绝对地址能力 | 多一道渲染，缓存要处理 | 备选（无统一入口时） |
| C nginx sub_filter | 反代时替换 JS 中的地址串 | 不改前端文件 | 脆弱（串变了就失效） | 仅过渡期 |

方案 A 前端最终态：
```js
window.base_api = '';            // 同源，走入口 /api 前缀
window.voice_api = '';           // 同源，走入口 /voice 前缀
```

## 六、api 容器化改造示例（其余同理）

```dockerfile
# api 镜像骨架（基于备份 tar/recovery.tar conda-pack）
FROM swr.cn-north-4.myhuaweicloud.com/ddn-k8s/docker.io/library/ubuntu:22.04-arm64
COPY recovery.tar /opt/recovery.tar
RUN mkdir -p /opt/envs && tar -xf /opt/recovery.tar -C /opt/envs && rm /opt/recovery.tar \
    && apt-get update && apt-get install -y --no-install-recommends libreoffice ffmpeg \
    && rm -rf /var/lib/apt/lists/*
ENV PATH=/opt/envs/bin:$PATH
WORKDIR /app
COPY code/chat_doc_0918 /app
# ASCEND_RT_VISIBLE_DEVICES 由编排注入（speech=6, api=0）
CMD ["python", "startup_obd.py", "--all-api", "--host", "0.0.0.0", "--port", "8261"]
```

⚠️ 待验证项（首台新环境必须先跑）：
1. conda-pack 环境在非源机 glibc 上的兼容性（麒麟 V10 → ubuntu/openEuler 基础镜像）；
2. `startup_obd.py` 是否支持 `--host`（否则 0.0.0.0 监听需改代码或 uvicorn env）；
3. LibreOffice/ffmpeg 在 arm64 Ubuntu 镜像内的字体（中文解析依赖字体包 `fonts-noto-cjk`）；
4. MindIE 容器从 host 网络 → bridge 后 `config.json ipAddress` 改 `0.0.0.0` 是否正常服务（TEI 已验证可行）。
