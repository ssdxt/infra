# 说明

本备份目录镜像 210（华为云 ssdxt, 113.44.11.210）部署关键文件结构（相对 "/" 的顶层：etc/ root/ ManualAI/）。

- `etc/rc.local` 因 Windows 无法创建该文件名未解压成功；其 NVIDIA 节点兜底块内容：
```
# NVIDIA device nodes (driver rpm installs no udev rules)
[ -e /dev/nvidia0 ] || mknod -m 666 /dev/nvidia0 c 195 0
[ -e /dev/nvidia1 ] || mknod -m 666 /dev/nvidia1 c 195 1
[ -e /dev/nvidiactl ] || mknod -m 666 /dev/nvidiactl c 195 255
[ -e /dev/nvidia-modeset ] || mknod -m 666 /dev/nvidia-modeset c 195 254
[ -e /dev/nvidia-uvm ] || mknod -m 666 /dev/nvidia-uvm c 195 253
```
（注：rc-local.service 为 static，默认不执行，主力靠 modules-load.d + udev 规则，见 210-配置手册.md 10.6.1）

- 备份时间：2026-09-03（驱动 550.163.01 / CUDA 11.8 / 全套修复后）
- 已排除：模型权重、mysql/redis 数据卷、日志、.venv/__pycache__/site-packages、大压缩包（omniknow2.tar.gz / ai-server_*.tar）
