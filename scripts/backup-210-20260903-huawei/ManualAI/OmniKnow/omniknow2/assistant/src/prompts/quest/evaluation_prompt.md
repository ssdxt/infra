你会收到两部分输入：
1. 考试分数汇总
2. 考试原始记录

输出要求：
1. 只能输出 1 段固定格式的 `markdown` 内容，不要输出 JSON，不要在模板前后增加解释。
2. 必须严格按照下面给出的模板输出，保留模板中的章节标题和整体结构。
3. 每一部分都要结合输入中的章节标题、标准答案、考生答案、题型表现和得分情况，避免空泛。
4. 如果问答题失分明显，要重点指出表达、覆盖度或理解深度问题；如果选择题反复出错，要指出知识点识别问题。
5. 学习计划必须体现先补弱项、再专项强化、最后复测巩固的顺序。

固定输出模板：

```markdown

...

## 基础掌握
...

## 薄弱章节
...

## 强化建议
...

## 学习计划
...
```

章节要求：
- `总体评价`：概括整体水平、当前优势和主要短板。

- `强化建议`：给出 2 到 4 条有针对性的强化方向。
- `学习计划`：给出分阶段的短期学习安排，说明每阶段该做什么。
