> 新环境从零复刻整套集群，**严格按步骤顺序**执行。每步：命令 + 预期输出 + 回滚。
> 前提阅读：README.md（复刻军规）、00-环境清单.md。
> 约定：`CTRL=10.100.10.10`；所有 kubectl 命令先 `export KUBECONFIG=/etc/kubernetes/admin.conf`。

## 步骤 0：前置检查（DNS / 时钟 / 磁盘 fio 验收）

### 0.1 网络与主机连通
```bash
for ip in 10.100.10.10 10.100.10.14 10.100.10.19 10.100.10.33 10.100.10.34 \
          10.100.10.39 10.100.10.41 10.100.10.44 10.100.10.45 10.100.10.46 10.100.10.47; do
  ping -c1 -W1 $ip >/dev/null && echo "$ip ok" || echo "$ip FAIL"; done
```
预期：11 台全 ok。失败：查交换机端口/VLAN，不继续。

### 0.2 清代理变量（kk 前置，防 90-踩坑 §2）
```bash
for ip in 10.100.10.{10,14,19,33,34,39,41,44,45,46,47}; do
  ssh root@$ip 'sed -i "/^http_proxy=/d;/^https_proxy=/d;/^HTTP_PROXY=/d;/^HTTPS_PROXY=/d;/^no_proxy=/d;/^NO_PROXY=/d" /etc/environment; rm -f /etc/profile.d/zz-proxy.sh'
done
# 安装机 shell：unset 全部 proxy 变量，env | grep -i proxy 必须为空
```
回滚：无需。

### 0.3 时钟（chrony，20-系统层 §1）
```bash
# .14 做内网 NTP 服务器，其余 10 台指向它（含删坏 drift）
bash /data1/ssdxt/storage/06-fix-chrony-ntp.sh    # 等 90 秒收敛
```
预期：总检查每台"已选源=1，Leap正常=1"；`node_timex_sync_status` 全 1。
回滚：恢复 `chrony.conf.bak2.*`。

### 0.4 磁盘 fio 验收（etcd 红线，40-存储 §4）
```bash
bash /data1/ssdxt/storage/05-etcd-migrate-to-fastdisk.sh check
```
预期：三台同步写 IOPS ≥1000、p99 ≤10ms、p99.9 ≤50ms。
**任一不达标 → 停，先找虚拟化方**（此时仍可按慢盘参数继续装机，但换盘前的绕行参数
（20-系统层 §2/§4）必须保留；达标则装完即可直接用正常参数）。

## 步骤 1：kk 装集群（10-k8s-install）

```bash
cd <kk 工作目录>
unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY no_proxy NO_PROXY
./kk create cluster -f config.yaml -a artifact.tar.gz
```
- 中断重跑：先执行 20-系统层 §7 的 kubelet 守卫清理（**别碰 control-01**）再重跑；
  死在 CoreDNS 时 `kubectl apply -f /etc/kubernetes/coredns.yaml` 再重跑。
- **create cluster 结束后（哪怕失败）立刻做步骤 2 的修正，再算装完。**

预期验证：
```bash

```
回滚：整体重建（kk 集群无部分回滚）。

## 步骤 3：Cilium KPR 迁移（30-网络 §1）

```bash

helm upgrade cilium /data1/ssdxt/charts/cilium-1.20.1.tgz -n kube-system \
  -f /data1/ssdxt/cilium-values-before-kpr.yaml \
  --set kubeProxyReplacement=true --set k8sServiceHost=10.100.10.250 --set k8sServicePort=6443 \
  --set gatewayAPI.enabled=true --timeout 15m

# 然后做 §1 的 4 个镜像修复（agent/init 去 digest、operator 镜像+command、envoy 长 tag）

```
预期：`cilium-dbg status | grep KubeProxyReplacement` → True；11 节点 Ready；
测试 Pod 连 `10.233.0.1:443` open。
回滚：见 30-网络 §1 回滚段。
