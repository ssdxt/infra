### 5. 离线镜像通道（WSL + skopeo + 代理）

**拓扑**：集群完全无外网；工作站上的 **WSL 是唯一能出外网的通道**（已装 skopeo / helm / regctl）。

```
上游 registry（走 HTTPS_PROXY=http://127.0.0.1:12450）
        │  skopeo copy --override-arch amd64
        ▼
Harbor harbor.wuxing.local（访问 Harbor 必须加 NO_PROXY 直连）
        │  节点 containerd 拉取（已配 insecure_skip_verify + 认证）
        ▼
集群
```

WSL 标准环境变量（每个会话先设）：

```bash
export HTTPS_PROXY=http://127.0.0.1:12450
export HTTP_PROXY=http://127.0.0.1:12450
export NO_PROXY='10.100.10.0/24,harbor.wuxing.local,localhost,127.0.0.1'
export no_proxy="$NO_PROXY"
```

批量搬运脚本：control-01 `/data1/ssdxt/images/mirror.sh`（在 WSL 执行，`bash mirror.sh all`，
清单维护在脚本内，`上游镜像|Harbor项目/仓库:tag` 一行一个）。

**纪律（复刻军规 #3）**：只取 amd64（`--override-arch amd64`）；Harbor 里的镜像都是**单架构**，
digest 与上游多架构 manifest 不同 → **任何 values/清单禁止 `@sha256:` 引用**，一律显式 `仓库:tag`。

helm chart 制品（全部在 control-01 `/data1/ssdxt/charts/`）：

```
cilium-1.20.1.tgz  cert-manager-v1.16.1.tgz  kube-prometheus-stack-62.7.0.tgz
longhorn-1.7.2.tgz  loki-6.24.0.tgz  alloy-0.12.0.tgz
nodelocaldns.yaml  gateway-api/experimental-install.yaml（Gateway API CRD v1.6.1 experimental）
```

### 6. SSH 访问方式（Windows 工作站）

```powershell
$env:SSH_ASKPASS='C:\Users\CC\Desktop\dsh\askpass.cmd'
$env:SSH_ASKPASS_REQUIRE='force'
$env:DISPLAY='localhost:0'
ssh root@10.100.10.10     # 密码认证，其余节点同理
```

**铁律**：PowerShell 5.1 会剥掉 ssh 远程命令里的**所有双引号** → 复杂逻辑必须在本地写成
`.sh`/`.py`（**LF 换行**）→ `scp` 到对方 `/tmp` → `ssh root@IP 'bash /tmp/x.sh'`。
详见 90-踩坑 §1。

## 【后补调整】

本章为基线，后补调整分布在各章；与环境有关的两条：

1. **内网 NTP（10.100.10.14）**：离线环境 `cn.pool.ntp.org` 解析不了，9 节点时钟不同步
   （偏差 0.9~1.4s）。已改为 .14 作服务器、其余 10 台指向它。见 20-系统层 §1。
2. **节点 100Mbps 网络**：镜像拉取 257MB 理论 ≥22s、实际曾 3m45s（Harbor 盘慢叠加）；
   Longhorn 副本数因此锁 2 不敢设 3。已向虚拟化方提出 ≥1Gbps 整改需求（未闭环）。

## 【验证命令】

```bash
# 节点连通（任一台跳板）
for ip in 10.100.10.10 10.100.10.14 10.100.10.19 10.100.10.33 10.100.10.34 \
          10.100.10.39 10.100.10.41 10.100.10.44 10.100.10.45 10.100.10.46 10.100.10.47; do
  ping -c1 -W1 $ip >/dev/null && echo "$ip ok" || echo "$ip FAIL"; done

# Harbor 可用性（任何节点）
curl -sk -u admin:'<HARBOR_PASSWORD>' https://harbor.wuxing.local/v2/_nowrap 2>/dev/null || \
curl -sk -u admin:'<HARBOR_PASSWORD>' https://harbor.wuxing.local/api/v2.0/health; echo

# Harbor 里镜像 tag 列表（确认要用的镜像已推上去）
curl -sk -u admin:'<HARBOR_PASSWORD>' 'https://harbor.wuxing.local/v2/cilium/cilium/tags/list'; echo

# 时钟同步状态（每台）
chronyc tracking | grep -E 'Reference ID|Stratum|System time'
chronyc sources | tail -3

# 磁盘 fsync 能力（etcd 达标线，见 40-存储 §5）
fio --name=t --rw=write --bs=8k --direct=0 --fdatasync=1 --iodepth=1 --size=1G \
    --filename=/tmp/fio.test --runtime=30 --time_based --group_reporting | grep -E 'IOPS|99.00th'

# 集群总检
export KUBECONFIG=/etc/kubernetes/admin.conf
kubectl get nodes && kubectl get pods -A --no-headers | grep -vE 'Running|Completed' || echo "全部 Running"
```
